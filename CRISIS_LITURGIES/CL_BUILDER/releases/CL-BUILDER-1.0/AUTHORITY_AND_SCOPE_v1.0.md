# Authority and Scope v1.0

Authority descends:

```text
CRISIS LITURGIES CANON
> CL-GEN-STD-001
> CL-METHOD-001
> RELEASE PROFILE
> FROZEN VOLUME SPECIFICATION
> PAGE SPECIFICATION
> RENDER PACKET
> MODEL OUTPUT
```

Builder 1.0 governs validation, compilation, authorization checks, QC, bounded repair records, deterministic assembly, receipts, and custody. It does not write canon, reinterpret locked prose, approve a concept, approve rendering, or turn model output into authority.

Two separate human gates are mandatory: `CONCEPT_APPROVED` before specification lock and `APPROVED_FOR_RENDER` before execution. Neither implies the other.
