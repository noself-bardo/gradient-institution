# CL-METHOD-001 — Proven Production Method v1.0

The method separates conceptual authority, generative image production, and deterministic publication assembly.

Every ordinary issue preserves four functions in order:

1. `RELIC_ENTRY`
2. `WITNESS_RECORD`
3. `SYSTEM_TRANSLATION`
4. `ARCHIVE_DISPOSITION`

A cover may exist only when separately classified and authorized. It does not enter or change the four-page function order. REFUSAL proves that this exception can remain bounded.

The image renderer owns visual evidence only. Authoritative typography, page geometry, margins, folios, citations, and final PDF construction belong to deterministic assembly.
