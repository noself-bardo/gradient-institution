# Deterministic Assembly Standard v1.0

Assembly owns locked manuscript text, typography, page geometry, margins, folios, citations, and PDF order. Given identical approved assets, manuscript, profile, fonts, and code, it must produce the same ordered content set and a recorded output checksum.

Renderer output is never trusted for authoritative wording. Missing assets may be represented in dry-run proofs, but a placeholder proof cannot be promoted as a final issue.
