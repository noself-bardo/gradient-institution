# QC Standard v1.0

Automated QC enforces the release profile: matte-black field, metallic-silver tonal family, controlled foreground coverage, edge black, closed transparency, restricted chroma, and no authoritative text in renderer-owned assets.

QC measures compliance; it does not judge conceptual adequacy. A technically passing plate still requires visual acceptance. The REFUSAL cover density exception applies only to its explicitly classified cover and cannot change ordinary interior limits.
