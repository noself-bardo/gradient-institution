# Production Workflow v1.0

The locked sequence is:

```text
Concept approval
→ editorial and issue lock
→ frozen specification
→ prompt compilation
→ render authorization
→ visual-only rendering
→ automated QC
→ bounded repair
→ visual-plate acceptance
→ deterministic typography
→ issue assembly
→ founder review
→ golden-reference freeze
→ custody verification
```

Concept approval, render authorization, visual acceptance, founder review, and golden-reference freeze are human decisions. Compilation, schema checks, QC measurements, assembly, manifests, and checksums are deterministic. Rendering is generative and may run only after the explicit gate opens.
